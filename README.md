## 처음 설치할 때

Tessera는 아직 Apple·Microsoft 유료 인증서로 서명하지 않아, 처음 한 번은 운영체제가 확인을 묻습니다.

**macOS**
1. 내려받은 `Tessera-macOS.dmg`를 열고 Tessera를 Applications 폴더로 끌어 놓습니다.
2. Tessera를 처음 열면 "확인할 수 없는 개발자" 안내가 뜹니다. **완료**를 누릅니다.
3. **시스템 설정 › 개인정보 보호 및 보안**의 맨 아래에서 Tessera 옆 **그래도 열기**를 누르고, 다시 묻는 창에서 **열기**를 누릅니다.

**Windows**
1. 내려받은 `Tessera-Windows-setup.exe`를 실행합니다.
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보**를 누른 뒤 **실행**을 누릅니다.
3. 관리자 권한 없이 설치됩니다. 인터넷이 없는 PC에는 폐쇄망용 설치본을 쓰세요(필요한 구성 요소가 함께 들어 있습니다).

## 업데이트

새 판이 나오면 앱이 알아서 알려 주고, 누르면 받아서 설치한 뒤 다시 시작합니다. 폐쇄망에서는 새 설치본을 받아 덮어 설치하면 됩니다.

## 이전 판(0.8.20)으로 돌아가기

0.9 판(새 화면 — 0.9.0·0.9.1)에서 문제가 있으면 언제든 0.8.20으로 돌아갈 수 있습니다. 0.9 판은 연결·설정·편집기 파일을 0.8.20이 읽는 형식으로 저장하므로 그대로 보입니다(0.9 판에서 바꾼 연결·설정도 이어집니다). 비밀번호는 0.8.20 때 저장한 것이 그대로 남아 있고, 0.9 판에서 새로 저장하거나 바꾼 비밀번호는 0.8.20에서 다시 넣어야 합니다. 연결 목록의 폴더·접힘·패널 크기와 스니펫은 0.9.1의 것이라 0.8.20에서는 보이지 않습니다(지워지지 않습니다 — 0.9.1로 돌아오면 다시 보입니다). 0.9.0을 처음 실행하기 전 상태는 앱 데이터 폴더의 `backup-before-0.9.0` 사본에 있습니다.

1. Tessera를 닫습니다.
2. [0.8.20 릴리스](https://github.com/smparkuntitle/tessera-releases/releases/tag/v0.8.20)에서 설치본을 받습니다 — 맥 `Tessera-0.8.20-arm64.dmg` · Windows `Tessera_0.8.20_x64-setup.exe`(폐쇄망 `Tessera_0.8.20_x64-offline-setup.exe`).
3. 그 위에 설치합니다(맥은 Applications 폴더에 덮어 놓기, Windows는 설치 파일 실행).
4. Tessera를 열면 0.8.20으로 열립니다. 맥은 앱이 바뀌었으므로 저장된 비밀번호를 처음 읽을 때 키체인 암호 창이 다시 뜹니다 — 로그인 암호를 넣고 [항상 허용]. 새 판 업데이트 알림이 오면 '나중에'를 누르세요.

## 이번 판에서 바뀐 점 (0.9.1)

### 고친 점
- **맥: 앱을 켤 때 키체인 암호 창에 늦게(15초 넘게) 답하면, 지난번에 열어 둔 편집기 글이 사라질 수 있던 문제를 고쳤습니다.** 0.9.0에서는 답을 기다리다 빈 화면으로 시작한 뒤 그 빈 화면을 저장해 이전 글을 덮었습니다. 이제 답이 올 때까지 이전 글을 덮지 않고, 답이 오면 그대로 되살립니다.
- 앱이 갑자기 꺼진 뒤(강제 종료·정전 포함) 다시 켜면 마지막으로 자동 저장된 편집기 글을 되살리고 알림으로 알려 드립니다. 앱이 스스로 죽은 경우에는 무슨 일이 있었는지 기록 파일을 남깁니다(설정 › 진단 › 문제 보고 묶음에 포함 — 비밀번호·쿼리 내용은 넣지 않습니다).
- 자동 저장을 끈 상태에서 저장하지 않은 글이 있으면, 앱을 닫기 전에 물어봅니다.
- 실행 중에 DB 연결이 끊기면 화면이 멈추지 않고 알림 띠로 알려 드립니다. 커밋하지 않은 변경이 사라졌는지, 커밋이 됐는지 알 수 없는지를 구분해 적고, [다시 연결] 단추를 둡니다. 끊긴 문장을 알아서 다시 실행하지는 않습니다.
- 새 문장을 실행할 때, 아직 저장하지 않은 그리드 편집이 말없이 지워지던 문제를 고쳤습니다. 편집이 남아 있는 결과는 지우지 않습니다.
- 저장된 비밀번호 파일을 읽을 수 없을 때(파일 손상·키체인 거부 등) 빈 비밀번호나 예전 비밀번호로 서버에 접속을 시도하지 않습니다(계정 잠금 횟수가 늘지 않습니다). 무엇이 문제인지와 다음에 할 일을 알림으로 안내하고, 설정 › 진단에서 상태를 볼 수 있습니다.
- 수동 커밋 탭에서 결과 표를 고치려 할 때, 저장 단계에 가서야 오류(TESSERA-TX-6001)가 나던 것을 미리 이유와 함께 알려 주도록 바꿨습니다.
- 행 상세 폼을 연 채 정렬·거르기를 해도 폼이 보던 행을 그대로 따라갑니다.
- MySQL·SQL Server 오류에도 쉬운 설명이 붙습니다(전에는 설명이 준비돼 있어도 보이지 않았습니다). 권한이 없어 실패한 경우의 설명을 네 DB 모두에 더했습니다.
- Oracle 11.2처럼 사전 조회가 느린 서버에서, 표를 고쳐 커밋한 직후 그 결과가 '편집 불가'로 바뀌던 문제를 고쳤습니다(편집 가능 여부를 묻는 답을 같은 연결에서 60초 동안 기억합니다. DDL·여러 문장 실행 뒤에는 다시 묻습니다).
- ⌘T(Ctrl+T)로 연 새 탭이 바로 글자를 받습니다(결과 표에 초점이 있을 때는 친 글자가 어디에도 들어가지 않았습니다).
- 화면 낭독기가 알림 띠, 폴더 삭제 확인창, '찾는 연결 없음' 안내를 읽습니다.
### 새 기능
- **연결 목록**: 운영/검증/개발 구역을 접고 펼 수 있고, 연결을 폴더로 묶을 수 있습니다. 목록 위 찾기 칸으로 이름을 걸러 봅니다. 접힌 상태와 폴더는 다시 켜도 그대로입니다.
- **패널 크기 조절**: 사이드바·편집기·결과 사이 경계를 끌어 크기를 바꿉니다. 결과 패널은 ⌘J(Ctrl+J)로 접고, 실행하면 다시 펴집니다. 크기는 다시 켜도 그대로이고, 명령 팔레트의 '패널 크기 기본값으로'로 처음 상태로 돌립니다.
- **스니펫**: 자주 쓰는 SQL을 이름·약어와 함께 저장해 두고, 편집기에서 약어를 치고 Tab을 누르거나 자동완성·명령 팔레트에서 골라 넣습니다. `${1:이름}` 자리표시는 Tab으로 옮겨 다닙니다. 파일로 내보내기·가져오기가 되고, 0.8.20에서 쓰던 스니펫은 스니펫 창의 '0.8.20 스니펫 가져오기'로 옮겨 옵니다(원래 파일은 그대로 둡니다).
- 단축키: 다음/이전 탭(⌘⇧]·⌘⇧[, Ctrl+Tab), n번째 탭(⌘1~9), 커밋(⌘⌥C)·롤백(⌘⌥R — 둘 다 확인창을 거칩니다), 실행 취소(⌘.), 내보내기(⌘⌥E), 변경 검토(⌘⇧R, 검토 창에서 ⌘↵로 커밋).
- 연결이 없는 탭에서 실행하면 [연결하고 실행]을 물어봅니다. 탭을 모두 닫은 뒤 여는 새 탭은 마지막에 쓰던 연결을 이어받습니다. 탭 목록에 연결 이름이 함께 보이고, 실행을 기다리는 문장이 있으면 탭 머리에 '대기 n'이 보입니다.
- 새 판이 있으면 상태줄에 표시가 뜹니다.
### 알아 둘 점
- 맥: 업데이트 뒤 처음 켤 때 키체인 암호 창이 뜨면 맥 로그인 암호를 넣고 **[항상 허용]**을 누르세요. 0.9.0 안내에 "다음 업데이트부터 한 번만 뜬다"고 적었지만, 몇 번 뜨는지는 아직 확인하지 못했습니다.
- 스니펫 내용은 암호화하지 않고 그대로 저장됩니다(내보낸 파일도 같습니다). 스니펫에 비밀번호를 적지 마세요.
- 키체인 창에서 [거부]를 누른 채로 쓰는 동안에는 저장된 비밀번호를 쓰는 연결이 모두 안내 알림과 함께 멈춥니다. 앱을 다시 켜고 [항상 허용]을 누르면 됩니다.
- 연결이 끊겨 "커밋됐는지 알 수 없음"으로 끝난 편집은, 표를 다시 조회해 들어갔는지 먼저 확인하세요(같은 행이 두 번 들어갈 수 있습니다). 다시 저장하려면 검토 창에서 확인 칸을 켜야 합니다.
- 연결 목록의 폴더·접힘·패널 크기는 0.9.0·0.8.20으로 돌아가면 보이지 않지만 연결 자체는 그대로입니다. 다시 0.9.1로 올라오면 다시 보입니다.

지난 판들의 노트는 [CHANGELOG.md](CHANGELOG.md)에 있습니다.

## 주요 기능

- **한 앱, 네 가지 DB** — 별도 클라이언트 설치 없이 바로 연결합니다. Oracle 11g도 Instant Client 없이 붙습니다.
- **글자가 깨지지 않는 연결** — US7ASCII·CP949 같은 오래된 문자셋의 한글도 서버에 있는 그대로 읽고 씁니다.
- **빠른 SQL 편집기** — 자동 완성, 문장 단위 실행, 탭마다 따로 쓰는 DB 세션, 실행 계획.
- **큰 결과도 가볍게** — 수십만 행 결과를 부드럽게 넘겨 보고, 표 안에서 바로 고쳐 저장합니다.
- **가져오기·내보내기** — CSV·TSV·엑셀·JSON·INSERT 문. 엑셀에서 복사한 내용을 표에 바로 붙여 넣습니다.
- **옮겨 오기 쉬움** — DBeaver·SQL Developer·DataGrip의 연결 목록을 가져옵니다(비밀번호는 가져오지 않음).
- **클라우드 DB** — AWS·Azure·Google Cloud·Oracle Cloud의 DB에 맞는 인증·보안 연결을 고릅니다.
- **비밀번호는 안전하게** — 운영체제 키체인(맥)·자격 증명 관리자(Windows)에만 저장합니다.

## 지원 환경

- **DB** — Oracle 11.2 이상 · PostgreSQL · MySQL / MariaDB · SQL Server
- **운영체제** — macOS(Apple Silicon) · Windows 10·11(64비트)
- **화면 언어** — 한국어 · English
